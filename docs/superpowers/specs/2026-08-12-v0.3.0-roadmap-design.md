# v0.3.0 roadmap: smart typing, zen/fullscreen, themes, settings, AI (chat + ghost text)

Date: 2026-08-12
Status: approved (owner)

Seven deliverables, executed in order, each on its own branch/PR. The release is cut
when all seven are merged. Closes #29 and #99.

## 1. PHP smart typing

- **Quotes auto-close, context-aware.** `'` and `"` currently only wrap selections
  (deliberate: `don't` in prose). New rule, using the already-parsed tree-sitter tree:
  auto-close when the cursor is NOT inside a comment or string node and NOT adjacent to
  a word character. Type-over applies: typing `'` when the next char is `'` steps past.
- **`=` becomes `=>` inside PHP array literals.** When the cursor is inside an
  `array_creation_expression` and the previous non-space char reads as a key (`'`, `"`,
  `]`, alphanumeric), typing `=` inserts `=>` (leading space only if missing).
  Typing `>` right after an auto-inserted `=>` is swallowed (no `=>>`). Outside arrays
  `=` is untouched.
- All through `insert_with_pairs`, one undo step, unit-tested.

## 2. Fullscreen + Zen mode

- **Fullscreen**: ⌃⌘F toggles native macOS fullscreen (gpui `toggle_fullscreen`),
  menu item under View.
- **Zen mode**: one action (⌘⇧Z... final binding chosen at implementation, avoiding
  conflicts) hides activity bar, sidebar, tab strip, and status bar; the editor gets
  centered max-width margins. Same action restores. State is session-only (not
  persisted).

## 3. More themes

Add popular palettes to the existing theme system: Dracula, Nord, Catppuccin Mocha,
Catppuccin Latte, Gruvbox Dark, Tokyo Night, Solarized Dark, Solarized Light. Each is
a full palette (all `Theme` fields, both syntax and chrome). Cycle/pick via the
existing theme mechanism + the settings panel (deliverable 4).

## 4. Settings UI

The ⌘, panel grows from a five-field form into sections: **Editor** (font, size,
autosave), **Appearance** (theme picker showing each theme's key colors, zen options),
**AI** (deliverables 5–7: provider, models, toggles, "Set API key…" button). Still
writes through `settings::update_settings`; JSON stays the power path.

## 5. AI provider layer

- Providers: **Anthropic API key** (Keychain), **`ant` CLI login** (token via
  `ant auth print-credentials --access-token`, Bearer + `anthropic-beta:
oauth-2025-04-20`), **custom base URL** (OpenAI-compatible wire: OpenAI, OpenRouter,
  local Ollama — no key needed for Ollama, nothing leaves the machine).
- Two wire formats: Anthropic `/v1/messages` SSE and OpenAI `/v1/chat/completions` SSE.
- **Transport is `curl -N` as a child process** (the self-update pattern): zero new
  crates, binary limit untouched, cancel = kill the child. Streaming parsed line-wise.
- **Keys live in the macOS Keychain** via the system `security` tool — never in the
  settings JSON (#99's hard rule).
- **Denylist**: `.env*`, `*.pem`, `id_*`, `*credentials*`, `*.sqlite`, key-ish files
  are refused as context, with no override.
- Defaults: chat `claude-opus-5`, autocomplete `claude-haiku-4-5` (latency), both
  configurable.
- `docs/RISKS.md` gains the data-egress entry #99 demands.

## 6. AI chat panel (right side) — closes #99

- Toggleable right panel (~380px): conversation, streaming reply, cancel button,
  code blocks with tree-sitter highlighting + copy, auto-scroll.
- **Context is explicit chips**: Selection / Current file / + file picker. Visible,
  removable, never automatic. Denylist enforced at attach time.
- Streaming repaints are batched (~50ms), never per-token (#93 idle/perf gate).
- Off by default; first open walks through provider setup.
- Out of scope (per issue): agentic file editing, tool use.

## 7. AI ghost-text autocomplete — closes #29

- Grey inline suggestion after the cursor, multi-line. **Tab** accepts, **Esc**
  dismisses, typing discards. Debounce ~400ms after typing pauses; in-flight request
  cancelled by newer ones.
- Context sent: a window of lines around the cursor from the **current file only**.
- Own toggle, off by default. Rendered distinctly (dim), never confused with LSP
  completions.

## Cross-cutting

- All network I/O via `cx.background_spawn`-style patterns, cancellable, no tokio.
- No new crate dependencies for AI (curl + security are macOS-bundled).
- CHANGELOG under Unreleased per deliverable; version bumps to 0.3.0 at release.
